# Changelog

## 0.1.0-alpha.0

- Added a beginner setup guide with experience level selection, project scan, recommended packs, and next actions.
- Added local Explain Selection for selected JavaScript and TypeScript code.
- Added hover explanations for known JavaScript terms.
- Added local Git and npm command explanations.
- Added project analysis for `package.json` scripts, dependencies, dev dependencies, and detected tools.
- Added a local pack registry with install status based on local pack files.
- Added suggested packs in Project Analysis and Setup Guide.
- Added a `package.json` dependency watcher that offers to refresh pack recommendations when new dependencies appear.
- Kept local explanations as the default and avoided telemetry, accounts, cloud sync, or analytics.
- Fixed hover support for JSX and TSX language modes.
- Added optional AI-powered explanations behind explicit user settings, with API keys stored in VS Code SecretStorage and local fallback guardrails.
