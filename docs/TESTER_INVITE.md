# DevTrail Beta Tester Invite

Use this as a simple message for 3-5 trusted testers.

---

Hi! I am testing DevTrail, a beginner-friendly VS Code extension that explains code, terminal commands, and project setup in plain English.

This is a beta build. It is useful enough to try, but explanations can still be incomplete, too simple, or wrong in places.

## How To Install

1. Download the DevTrail `.vsix` from the GitHub release link I send you.
2. Open VS Code.
3. Open the Command Palette.
4. Run `Extensions: Install from VSIX...`.
5. Choose the downloaded `devtrail-0.4.0-beta.0.vsix` file.
6. Reload VS Code if prompted.
7. Run `DevTrail: Open Setup Guide`.

## What To Try First

1. Run `DevTrail: Open Setup Guide`.
2. Open a JavaScript, TypeScript, React, or JSX file and hover over terms like `const`, `map`, `props`, `children`, or `useEffect`.
3. Highlight a small, non-private code snippet and run `DevTrail: Explain Selection`.
4. Run `DevTrail: Explain Command` and try `git status`.
5. Run `DevTrail: Analyze Project` in a project with `package.json`.
6. Open `DevTrail: Manage Packs` and try installing or uninstalling a bundled pack.

Optional: if you are comfortable using your own OpenAI API key, you can enable AI explanations. DevTrail works without AI, so this is not required.
