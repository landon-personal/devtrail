# DevTrail v1 Release Candidate

`v1.0.0-rc.0` is the release candidate for DevTrail v1.

This means DevTrail is in feature freeze. Do not add major new features before v1.0.0 unless a serious bug appears.

## Focus Before v1

- Reliability
- Clear setup and install flow
- Documentation accuracy
- Privacy and local-first behavior
- Friendly wording for beginners
- Broken links, missing release notes, or install issues

## What Testers Should Report

- Bugs or crashes
- Confusing setup steps
- Confusing explanation wording
- Broken links or bad download instructions
- Keyboard shortcut conflicts
- Status bar or right-click action problems
- AI opt-in or fallback behavior that feels unclear

## What Should Wait Until After v1

- Major UI redesigns
- New pack marketplace behavior
- Remote pack downloads
- Accounts, sync, telemetry, analytics, payments, or tracking
- New explanation engines or large feature areas

## Safety Reminder

Do not ask testers to share API keys, `.env` files, private source code, school/private data, access tokens, passwords, or other secrets. Use tiny fake examples when reporting explanation bugs.
