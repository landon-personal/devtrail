# DevTrail Shortcuts

DevTrail includes default keyboard shortcuts for common actions. You can change or remove them in VS Code Keyboard Shortcuts.

## Default Shortcuts

| Action | Mac | Windows/Linux | What It Does |
| --- | --- | --- | --- |
| Explain Selection | `Cmd+Alt+E` | `Ctrl+Alt+E` | Explains the code you highlighted. |
| Explain Command | `Cmd+Alt+C` | `Ctrl+Alt+C` | Opens a prompt to explain a Git or npm command. |
| Open Setup Guide | `Cmd+Alt+D` | `Ctrl+Alt+D` | Opens the DevTrail setup guide. |
| Manage Packs | `Cmd+Alt+P` | `Ctrl+Alt+P` | Opens bundled local pack management. |
| Change Explanation Level | `Cmd+Alt+L` | `Ctrl+Alt+L` | Switches between Beginner, Learning, and Advanced explanations. |

## Other Quick Access

- Click `$(sparkle) DevTrail` in the VS Code status bar.
- Run `DevTrail: Quick Start`.
- Right-click selected code and choose `DevTrail: Explain Selection`.
- Right-click in the editor to open setup or change explanation level.

## Change Shortcuts

1. Open VS Code.
2. Open the Command Palette.
3. Run `Preferences: Open Keyboard Shortcuts`.
4. Search for `DevTrail`.
5. Click the pencil icon next to a shortcut.
6. Enter your preferred keybinding.

VS Code users can override all DevTrail keybindings. If a shortcut conflicts with another extension, change either shortcut in Keyboard Shortcuts.
