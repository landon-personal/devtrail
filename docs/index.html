What DevTrail does

Explain selected code

Highlight JavaScript, TypeScript, React, or JSX and get a plain-English breakdown.

Hover terms

Hover terms like const, map, useEffect, props, and children for short explanations.

Explain commands

Understand beginner Git and npm commands before you run them.

Analyze projects

Read package.json and see scripts, dependencies, tools, and suggested packs.

Install learning packs

Enable bundled local packs for React, TypeScript, Tailwind, Vite, Git, npm, and more.

Choose explanation depth

Use Beginner, Learning, or Advanced depending on how much help you want.

Install the beta

  1. Download devtrail-0.5.0-beta.0.vsix from the v0.5 GitHub release.
  2. Open VS Code.
  3. Run Extensions: Install from VSIX....
  4. Select the downloaded file.
  5. Reload VS Code if prompted.
  6. The setup guide should open automatically. You can also run DevTrail: Open Setup Guide.

Local-first privacy

DevTrail is local-first. Local explanations, hover text, command explanations, project scans, pack recommendations, and bundled pack install state run on your machine.

No analytics. No telemetry. No tracking. No accounts. No cloud sync. No payments. No external scripts on this page.

Optional AI

AI explanations are off by default. Selected code may be sent to OpenAI only if you enable AI, store your own API key in VS Code SecretStorage, and run Explain Selection on code that passes local safety checks.

If AI is disabled, missing a key, blocked by safety checks, canceled, or unavailable, DevTrail uses local explanations.

Beta warning

This is a beta. Some explanations will still be incomplete, too simple, or wrong. Use DevTrail as a learning helper, not as a source of guaranteed correctness.

FAQ

Who is DevTrail for?

Beginners learning JavaScript, TypeScript, React, Git, npm, and modern web project structure.

Does DevTrail send my code anywhere?

Not by default. Local features stay on your machine. Optional AI sends selected code only after you enable AI and configure an API key.

Are packs downloaded from the internet?

No. In this beta, packs are bundled JSON/content files and are enabled locally in VS Code state.

Is this on the VS Code Marketplace?

Not yet. The beta is installed from a local .vsix file.

Feedback

Open a GitHub issue when the repo is public. Helpful feedback includes the DevTrail version, VS Code version, your operating system, the command you ran, installed packs, explanation level, and what felt confusing.

Do not paste API keys, .env values, private source code, school/private data, or secrets. Use a tiny fake code sample when possible.
