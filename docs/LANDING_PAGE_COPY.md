## Headline

Understand your code without leaving VS Code.

## Subheadline

DevTrail is a beginner-friendly VS Code extension that explains selected code, terminal commands, and project setup in plain English.

## Feature Bullets

- Highlight code and get a beginner-friendly explanation.
- Hover JavaScript, TypeScript, and React terms for quick definitions.
- Explain common Git and npm commands before you run them.
- Scan `package.json` to understand scripts, dependencies, and tools.
- Install bundled local packs for React, TypeScript, Tailwind, Vite, Git, and npm.
- Optionally enable AI explanations when you want extra help.

## Privacy Note

DevTrail is local-first. Local explanations, project scans, command explanations, and bundled packs run on your machine. AI explanations are optional and only send selected code after you enable AI and set your own API key.

## Install Steps

1. Download the `.vsix` file.
2. Open VS Code.
3. Run `Extensions: Install from VSIX...`.
4. Select the downloaded DevTrail file.
5. Run `DevTrail: Open Setup Guide`.

## Beta Warning

DevTrail is in beta. Some explanations will be incomplete or imperfect. Please report confusing, vague, or incorrect explanations so the local packs and patterns can improve.
